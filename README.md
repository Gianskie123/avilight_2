# AviLight: Spatio-Temporal Forecasting of Bird Richness Variability Driven by Artifical Light Pollution Using XGBoost and ConvLSTM

AviLight is a thesis project that investigates how **artificial light at night (ALAN)** and environmental factors influence **bird species richness across space and time**, using **machine learning and deep learning models**.

This repository contains all **code, system components, and documentation** required to reproduce the analysis, models, and visualizations used in the thesis.

---

## Research Objectives

1. Quantify spatial and temporal patterns of artificial light intensity using satellite data.
2. Analyze the relationship between ALAN and bird species richness.
3. Develop predictive models using:
   - Tree-based machine learning (XGBoost)
   - Spatio-temporal deep learning (ConvLSTM)
4. Compare model performance and interpret results in an ecological context.
5. Integrate the final models into a system or web-based application for visualization and analysis.

---

## Models Used

- **XGBoost**
  - Baseline and interpretable machine learning model
  - Used for feature importance and tabular prediction

- **ConvLSTM**
  - Deep learning model for spatiotemporal patterns
  - Captures spatial grids and temporal dependencies
